# FIFA21 Data Cleaning and Preprocessing

## Overview
This project demonstrates a complete data cleaning and preprocessing workflow using the FIFA 21 player dataset. Real-world datasets often contain inconsistencies, missing values, incorrect data types, and formatting issues. The objective of this project is to transform a messy dataset into a clean and structured format suitable for data analysis.

The notebook documents the step-by-step process used to inspect, clean, and prepare the dataset using Python and Pandas.

---

## Dataset
The dataset contains player information from FIFA 21, including attributes such as player ratings, club information, contract details, financial values, and performance statistics.

Like many real-world datasets, the raw data contains:
- inconsistent formatting
- incorrect data types
- missing values
- columns requiring transformation

These issues are addressed during the cleaning process.

---

## Project Objectives
- Inspect and understand the structure of the dataset
- Identify data quality issues
- Clean and standardize the data
- Convert columns to appropriate data types
- Prepare the dataset for analysis or modeling

---

## Data Cleaning Process

### Data Inspection
- Loading the dataset
- Exploring dataset structure
- Reviewing column data types
- Identifying problematic columns

### Data Cleaning
- Handling missing values
- Cleaning text and categorical variables
- Removing unnecessary columns
- Standardizing column formats

### Data Transformation
- Converting columns to numeric values
- Parsing financial and contract information
- Formatting columns for analysis
